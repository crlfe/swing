# API Reference

This document tracks the core architecture and API of the project.

## Core Modules

- `src/main.ts`: Entry point of the application.
- `src/state.ts`: Manages the global application state.
- `src/util.ts`: General utility functions.

## UI Components

- `src/ui-chat.ts`: Chat interface logic.
- `src/ui-sidebar.ts`: Sidebar navigation and management.
- `src/ui-tabs.ts`: Tabbed interface for documents/tools.

## Logic & Data

- `src/chat/`: Chat-specific logic and message handling.
- `src/data/`: Data persistence and retrieval.
- `src/editor.ts`: Text editor implementation and integration.
- `src/preview.ts`: Document preview functionality.
- `src/tools/`: Implementation of available tools.

## Other

- `src/cli/`: Command line interface extensions.
- `src/h.ts`: Helper functions for DOM manipulation.
- `src/fs-example.ts`: Example of file system interactions.
